# 泰捷电视直播 v1.2.0（WE30C 深度定制版）

基于 [CCTV_Viewer](https://github.com/Eanya-Tonic/CCTV_Viewer) 重写，针对 **泰捷 WE30C（RK3229 四核 Cortex-A7 / Mali-400 / 1GB 内存 / Android 4.4.4 / 32 位）** 精简适配。

## 一、编译

```bash
./gradlew assembleDebug     # 需 JDK 17 + compileSdk 32
# 产物：app/build/outputs/apk/debug/泰捷电视直播_v1.2.0.apk
```

X5 内核包已内置在 `app/src/main/assets/045738_x5.tbs.apk`（32 位版，适配 RK3229），
构建出的 APK 自带内核，无需联网下载 36MB。（详见《编译环境搭建指南》，含 GitHub Actions 免环境编译方案）

## 二、安装

1. 卸载旧版（不同来源的包签名不同，覆盖安装会失败）。
2. 盒子 → 设置 → 安全 → 打开「未知来源」，或用 `adb install`。
3. **首次打开会停在引导页 1–3 分钟**装 X5 内核（RK3229 解包 + dexopt 慢），别断电。
   装完会**自动重启一次应用**来加载内核（这是 X5 的硬性要求），属正常现象。
   超过 4 分钟会自动放行并改用系统内核，不会卡死。
4. 若提示"X5 内核未就绪"：进 **设置 → 内核诊断** 查看原因，或用 **重新安装 X5 内核** 重试。

## 三、遥控器键位

| 按键 | 功能 |
|---|---|
| 上 / 下 | 打开换台列表并预选相邻频道（设置里可改为直接换台） |
| 确认 | 显示当前频道、节目预告与画质，并打开换台列表 |
| 左 / 右 | 在换台列表中切换「央视频道 / 地方频道」 |
| 菜单键（或 M） | 底部菜单：**刷新 / 播放暂停 / 全屏 / 清晰度 / 设置** |
| 数字键 | 直接输入台号换台，2.5 秒超时生效，如 `21` 切北京卫视 |
| 返回（或 B） | 2 秒内连按两次退出 |
| 音量键 | 调节音量 |

## 四、清晰度（v1.1.0 新增，默认标清）

- **默认标清 480P**，适合 1GB 内存 + 百兆网口的弱机。
- 两种改法：
  - **实时**：播放页按菜单键 → 左右键选「清晰度」→ 确认键循环切换（自动→流畅→标清→高清→超清），立即生效并记住选择。
  - **默认**：设置 → 画质 → 默认清晰度，下次换台生效。
- 匹配策略（三级兜底，兼容两个站点不同的 UI）：
  1. 央视网精确 id：`resolution_item_{360|480|540|720|1080}_player`
  2. 选项文字：央视网「流畅/标清/高清/超清」，央视频「540P/720P/1080P/蓝光」
  3. 面板未展开时，先点「清晰度/画质/码率/自动」再选
- **注意**：央视频网页端最低档是 **540P**（没有 480P），选标清时会落到 540P，属正常。
- 若切换到高清/超清后卡顿，切回标清即可；设成「自动」则完全不干预网页默认。

## 五、节目源（官方网页源，2026-09-29 逐个抓取验证）

| 台号范围 | 主源 | 备用源 | 验证 |
|---|---|---|---|
| 1–20 央视全套 | 央视网 `tv.cctv.com/live/xxx` | 央视频 pid | 20 个页面全部返回正确频道名与节目单 |
| 21–41 地方卫视 | 央视频 `yangshipin.cn/tv/home?pid=xxx` | 无（央视网无卫视） | pid 经多份公开频道表交叉核对 |

**为什么央视台改用央视网做主源**：央视频是 Vue 单页应用，A7 上首屏要执行大量 JS，明显偏慢；央视网是传统页面，DOM 更轻、换台更快，且播放器有精确的清晰度 id 可用。

个别台说明：
- CCTV-3 / 6 / 8 央视频网页端受限 → 无备用源，只走央视网（已验证可播）。
- CCTV-16 的央视频 pid 抓取时未稳定返回频道名，故主源用已验证的央视网 `cctv16`。
- 河北卫视 pid 页面偶发会员提示，属央视频侧限制，非地址错误。

频道表集中在 `Channel.java`，改台只需改那一张表。

## 六、为 WE30C 做的适配

| 项目 | 处理 |
|---|---|
| 1GB 内存 | 去掉原版双缓冲双 WebView，只保留一个；换台前先 `about:blank` 释放上一页 |
| Mali-400 / 4K 输出 | 缩放按 1920×1080 基准计算并**封顶 100%**（原版 4K 屏会按 200% 渲染直接卡死） |
| Android 4.4.4 | 全部 JS 用 ES5 写法（不用箭头函数）；中文关键匹配词用 unicode 转义，避免 Windows 下编译乱码 |
| 32 位内核 | 固定安装 045738（32 位），不做 64 位探测，避免装错内核导致无限重启 |
| 弱 CPU / 百兆网口 | 无图加载 + 清空无关栏目块 + 默认标清；后台 `pauseTimers`，内存紧张时清缓存 |
| 弱网/改版 | 主源失败或 12 秒无画面自动回落备用源，不再白屏干等 |
| 代码量 | 主逻辑由原版 1308 行降到约 600 行，两套站点脚本合并成一套 |
